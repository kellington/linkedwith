####  1. /gsd:new-project

I want to build a tool that can take exported LinkedIn data and make it more useful for the user.  the LinkedIn application - especailly on mobile - is very frustrating to most people.  I would like the result to be a very simple method of parsing my own data, creating an easy to use list of my contacts and how I have interacted.  I also would like a way that I can have my own notes about each contact.  The expectation is that on a schedule, I would do a refresh (download-my-data) from linkedIn and when the new zip file comes, the process would parse it, identify changes in key data files and update my own data store.

Using the "Connections.csv" would be the basis - as it has th following fields:
- First Name
- Last Name
- URL
- Email Address
- Company
- Position
- Connected On

Notes about that file:
1. "Connected On" is a key field and default sort column
2. "Email Address" is always missing - LinkedIn doesn't share.  So I would like a way to update that field. 

What I would add is
- "Most Recent Message On"  (date)
- "Most Recent Interaction On" (date - of latest reaction, comment, post, etc)
- "Phone Number"

In terms of easy to use - perhaps the result is just a simple HTML page with javascript.  On iPhone, I could open using a tool such as Html Preview https://apps.apple.com/ca/app/html-preview-quick-inspector/id6760443436

To create, it should be a command line tool or python script - wrapped in a Claude SKILL.  Perhaps it is a 2 step process
1. Expand downloaded ZIP and compare new csv files with previous for changes
2. Update a local data store as needed
3. Merge any new "contact_info.csv" file that may be available
4. Generate "LinkedWith.HTML" file

The local data store could be whatever is simple - a CSV, JSON, etc.
the "contact_info.csv" should be any "updates" that the user can provide - for each connection it could include either email or phone
