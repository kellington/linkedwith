What This Tool Does

LinkedWith parses a LinkedIn data export ZIP into an enriched, sortable HTML contact list. It combines connections, message history, and user-provided contact info (email, phone, notes) into a single self-contained HTML page — viewable offline and on iPhone via the HTML Preview app. The goal: turn frustrating LinkedIn data into a simple contact list enriched with interaction history and personal notes, accessible on any device without an internet connection.

What One Run Produces

Reads LinkedIn ZIP → merges contact info → writes JSON store → generates HTML.

How to Run — Quick Reference
1 Download fresh LinkedIn data
Settings & Privacy → Data Privacy → Get a copy of your data → "Download larger data archive"
Takes ~15 minutes for initial files; full message history can take longer.
2 Drop the ZIP into data/LinkedIn/
mv ~/Downloads/Complete_LinkedInDataExport_*.zip data/LinkedIn/
3 Run the pipeline
uv run python linkedwith.py data/LinkedIn/<zip-filename>.zip
Or equivalently: python linkedwith.py data/LinkedIn/<zip-filename>.zip
4 Open the output
open output/LinkedWith.HTML   # Mac
# or copy to iPhone and open with "HTML Preview" app
Optional — Add contact info
Edit data/contact_info.csv with columns: URL, First Name, Last Name, Email, Phone, Notes
URL is the preferred match key (normalized LinkedIn profile URL).
Re-run to merge — user-added fields survive re-imports.

V1.1 Ideas — Not Commitments
Relationship Decay Scoring
Model how connections go "cold" over time using a half-life formula based on message frequency and shared history. Flag relationships that are decaying fastest but still worth saving. Base half-life: 180 days with modifiers for depth of interaction.
Reciprocity Debt Ledger
Track who you owe a message vs. who owes you, scored by endorsements, recommendations, and message depth. Surfaces the connections where you've given more than you've received and vice versa.
Warm Path Discovery
Find mutual connections to reach a target company. Scores each bridge by both relevance (industry proximity, alumni networks) and warmth (message history, recency). A standalone prompt for this already exists in project/ideas/.
Network Intelligence Dashboard
Six-analysis deep-dive: half-life decay, reciprocity ledger, vouch scores, conversation resurrection, network archetype classification, and warm path demo — designed for a quarterly one-time analysis run. Full prompt and workflow documented in project/ideas/.
v1.0 is the useful thing. These are enhancements for when a business use case emerges.
Known Constraints — Read Before Changing Anything
iPhone Output: Self-Contained Only
HTML must have no external dependencies — no CDN, no external fonts, no external JS. All CSS and JavaScript must be inline. Break this and the output stops working on mobile.
UTF-8 BOM on LinkedIn CSVs
LinkedIn exports ship with UTF-8-sig encoding. Always open CSVs with encoding="utf-8-sig". Using "utf-8" causes the BOM to appear in the first column header, silently breaking all column lookups — no error thrown.
Incremental Updates — Store is Merge, Not Replace
Re-running preserves user-added fields (email, phone, notes). The store appends and merges — it never silently deletes contacts, even if they've disappeared from LinkedIn. This is intentional.
"No Longer in LinkedIn Export" Message
Informational only. Contacts removed from LinkedIn are not deleted from the store. You may have email/phone/notes for them — deleting silently would be destructive.
No Database — Flat JSON by Design
data/linkedwith.json is a flat file store. This is intentional: no schema migrations, no DB overhead for a personal single-user tool. Don't introduce SQLite or any DB without a compelling reason.
