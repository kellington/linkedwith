1Purpose

LinkedWith parses a LinkedIn data export ZIP into an enriched, searchable HTML contact list. It combines connections, message history, and user-provided contact info (email, phone, notes) into a single self-contained HTML page — viewable offline and on iPhone via an HTML Preview app. The goal: turn frustrating LinkedIn data into a simple contact list enriched with interaction history and personal notes.

2What One Run Builds

  • Reads Connections.csv and messages.csv from the LinkedIn ZIP
  • Merges data/contact_info.csv — your own email / phone / notes
  • Writes data/linkedwith.json — the enriched data store, which persists across runs
  • Generates output/LinkedWith.HTML — one file, inline CSS and JS, no internet required

What the page does rebuilt 2026-08-19

  • Search across name, company, position, email, phone and notes. Multiple words are ANDed and matches are highlighted. / focuses the box, esc clears it
  • Filter chips — Messaged, Notes, Email / phone. Chips stack with each other and with the search
  • Year dropdown for connection year
  • Sort by connected date, last message, name or company. Blanks always sort last
  • Two views over the same filtered set — Cards (built for the phone) and Table (sortable columns, sticky header)
  • Tap a name for the LinkedIn profile, an email to compose, a phone to dial, or a company to filter to it
  • Light and dark aware
The rebuild made the file smaller — 207 KB vs 289 KB — because the rows embed once as a JSON array instead of as repeated table markup.

3How to Run

What to do when a new export arrives.

Step 1 — Download fresh LinkedIn data

Settings & Privacy → Data Privacy → Get a copy of your data → Download larger data archive. Initial files land in about 15 minutes; full message history can take longer.

Step 2 — Drop the ZIP into data/ 
mv ~/Downloads/Complete_LinkedInDataExport_*.zip data/
Step 3 — Run it 
uv run python linkedwith.py data/Complete_LinkedInDataExport_08-18-2026.zip.zip

Or ask Claude: "run linkedwith" — the skill finds the newest export itself.

Step 4 — Open the output 
open output/LinkedWith.HTML

Or copy it to the iPhone and open it with the HTML Preview app.

Optional — add contact info

Edit data/contact_info.csv, columns URL, First Name, Last Name, Email, Phone, Notes. URL is the preferred match key; name is the fallback. Re-run to merge.

Tests

uv run pytest

7Known Constraints

iPhone output — the HTML must stay self-contained. No CDN, no external fonts, no external JS. Break this and it stops working offline. Profile / mailto / tel links are fine: a link you tap is not a request the page makes.
UTF-8 BOM — LinkedIn exports ship UTF-8-sig. Always open CSVs with encoding="utf-8-sig" or the first column header silently breaks.
Escaping in the embedded JSON — rows go into a <script> block, so <, > and & must be \u-escaped and passed through Jinja |safe. Autoescape alone produces a blank page.
Incremental updates — re-running preserves user-added fields (email, phone, notes). The store merges, it does not replace.
"No longer in LinkedIn export" — informational only. Contacts are never deleted from the store, even after they disappear from LinkedIn.
No database — the flat JSON store is intentional. No schema migrations, no DB overhead for a single-user personal tool.
