Purpose

LinkedWith parses a LinkedIn data export ZIP into an enriched, sortable HTML contact list. It combines connections, message history, and user-provided contact info (email, phone, notes) into a single self-contained HTML page — viewable offline and on iPhone via an HTML Preview app. The goal: turn frustrating LinkedIn data into a simple contact list enriched with interaction history and personal notes.

What It Builds

  • Reads Connections.csv and messages.csv straight from the LinkedIn ZIP (no extraction to disk)
  • Merges data/contact_info.csv — your own email / phone / notes
  • Writes data/linkedwith.json — the enriched store, persists across runs
  • Generates output/LinkedWith.HTML — inline CSS/JS, no internet required, light/dark aware

Page features: search (multi-word AND, highlighted, / to focus) · filter chips Messaged, Notes, Email / phone · connection-year dropdown · Cards view for phone, Table view (sortable, sticky header) for desktop · blanks always sort last.

How to Run — when a new export arrives

1

Download fresh LinkedIn data

Settings & Privacy → Data Privacy → Get a copy of your data → “Download larger data archive”
Direct link: linkedin.com/mypreferences/d/download-my-data · initial files ~15 min; full message history can take longer. The quicker “Basic” archive also contains Connections.csv + messages.csv — enough for this tool.

2

Drop the ZIP into data/

mv ~/Downloads/*_LinkedInDataExport_*.zip data/

Exports currently live directly in data/ (there is no data/LinkedIn/ subfolder). LinkedIn names often end in a double .zip.zip — that's fine.

3

Run

uv run python linkedwith.py data/<zip-filename>.zip
# or
python linkedwith.py data/<zip-filename>.zip
# or, inside Claude Code
/linkedwith

Last run: uv run python linkedwith.py data/Basic_LinkedInDataExport_09-09-2026.zip.zip

4

Open the output

open output/LinkedWith.HTML   # Mac

Or copy to iPhone and open with the “HTML Preview” app.

Optional — add contact info. Edit data/contact_info.csv, columns URL, First Name, Last Name, Email, Phone, Notes (all optional per row). Match order: normalized profile URL first, then case-insensitive First + Last name (skipped with a warning on 0 or 2+ matches). Re-run to merge — lands as user_email / user_phone / user_notes and survives future imports.

Known Constraints

iPhone output must be self-contained — no CDN, external fonts or external JS. Break this and it stops working on mobile.
UTF-8 BOM — LinkedIn CSVs are UTF-8-sig. Always open with encoding="utf-8-sig" or column lookups silently break.
Incremental updates — re-running merges, never replaces; user-added email / phone / notes are preserved.
“No longer in LinkedIn export” — informational only. Contacts that vanish from LinkedIn are not deleted from the store.
No database — the flat JSON store is intentional: no migrations, no DB overhead for a single-user tool.
Public repo — data/, output/, *.zip, *.csv are git-ignored. Never commit exports or the generated HTML (audited clean 2026-09-10).
